FormaForm 위젯 데모

1. 텍스트 · 숫자 (7종)
text
기본 텍스트 입력. type: 'number' 으로 숫자 모드, prefix/suffix 로 단위 표시.
코드
{ field: 'text', label: 'text', placeholder: '한 줄 텍스트', maxLength: 50 }
{ field: 'num',  label: 'number', type: 'number', suffix: '개', min: 0, max: 999 }
textarea
여러 줄 텍스트. rows 로 표시 높이 지정.
코드
{ field: 'memo', label: 'textarea', widget: 'textarea', rows: 3, placeholder: '여러 줄 입력' }
password
비밀번호 입력 — 우측 눈 아이콘으로 표시/숨김 토글.
코드
{ field: 'pw', label: 'password', widget: 'password', placeholder: '8자 이상' }
hidden
숨김 필드 — UI 에 노출되지 않지만 getData() 에는 포함. 화면 ID/PK 같은 값 유지에 사용.
코드
{ field: 'pk', widget: 'hidden' }
// setData({ pk: 'ITM-001' }) 로 값 보존, getData() 에 포함
currency
금액 — 천단위 콤마 자동 포맷. prefix/suffix 로 통화/단위.
코드
{ field: 'amt', label: 'currency', widget: 'currency', prefix: '₩', suffix: '원' }
inputMask
입력 마스크 — 9 숫자, a 영문, * 영숫자.
코드
{ field: 'tel', label: 'inputMask', widget: 'inputMask', mask: '999-9999-9999', placeholder: '010-1234-5678' }
address
카카오 주소 검색 — 검색 버튼 클릭 시 우편번호 / 주소 / 상세주소 분리 입력. getData() 에서 field_zip / field_addr / field_detail 로 분리 반환.
코드
{ field: 'addr', label: 'address', widget: 'address' }
// getData() → { addr_zip: '06234', addr_addr: '...', addr_detail: '...' }
2. 선택 (8종)
combo
검색 가능 드롭다운. options 인라인 또는 code 로 서버 코드 그룹 조회.
코드
{ field: 'grade', label: 'combo', widget: 'combo', options: [
    {value:'A',label:'A형'}, {value:'B',label:'B형'}, {value:'C',label:'C형'}
]}
// 서버 코드 그룹: { code: 'GRADE' }   ← tb_code 의 GRADE 그룹 자동 조회
select
단순 HTML <select>. combo 보다 가벼움. 적은 옵션·검색 불필요한 경우.
코드
{ field: 'use', label: 'select', widget: 'select', options: [
    {value:'Y',label:'사용'}, {value:'N',label:'미사용'}
]}
radio
라디오 버튼 — 2~4개 옵션의 즉시 선택에 적합.
코드
{ field: 'gender', label: 'radio', widget: 'radio', options: [
    {value:'M',label:'남'}, {value:'F',label:'여'}, {value:'O',label:'기타'}
]}
checkbox
단일 체크 — 'Y' / 'N' 값. checkLabel 로 옆 텍스트.
코드
{ field: 'agree', label: 'checkbox', widget: 'checkbox', checkLabel: '이용약관 동의' }
switch
ON/OFF 토글 — 'Y' / 'N' 값. onLabel/offLabel 로 텍스트 커스텀.
코드
{ field: 'active', label: 'switch', widget: 'switch', onLabel: '사용', offLabel: '중지' }
multiCombo
복수 선택 — 콤마 구분 문자열 'A,B,C' 로 반환.
코드
{ field: 'tags', label: 'multiCombo', widget: 'multiCombo', options: [
    {value:'A',label:'항목 A'}, {value:'B',label:'항목 B'},
    {value:'C',label:'항목 C'}, {value:'D',label:'항목 D'}
]}
// getData() → { tags: 'A,C' }
buttonGroup
버튼 그룹 단일 선택 — 좌/중/우, 일/주/월 같은 짧은 옵션에 적합.
코드
{ field: 'align', label: 'buttonGroup', widget: 'buttonGroup', options: [
    {value:'L',label:'좌'}, {value:'C',label:'중'}, {value:'R',label:'우'}
]}
autocomplete
자동완성 — 타이핑하면 옵션 필터. 인라인 options 또는 서버 fetchUrl.
코드
{ field: 'fruit', label: 'autocomplete', widget: 'autocomplete', options: [
    {value:'apple',label:'Apple'}, {value:'banana',label:'Banana'},
    {value:'cherry',label:'Cherry'}, {value:'durian',label:'Durian'}
]}
3. 날짜 · 기간 (7종)
date
날짜 — 캘린더 팝업. default: 'TODAY' 로 오늘 자동 설정.
코드
{ field: 'reg', label: 'date', widget: 'date', default: 'TODAY' }
// getData() → { reg: '2026-05-15' }
dateRange
기간 선택 — 시작/종료 두 캘린더 + 프리셋(오늘/이번주/이번달/지난달). field_from / field_to 로 분리 반환.
코드
{ field: 'period', label: 'dateRange', widget: 'dateRange', default: 'THIS_MONTH' }
// getData() → { period_from: '2026-05-01', period_to: '2026-05-31' }
yearMonth
년월 — 'YYYY-MM'. 회계/매출 마감월 등에.
코드
{ field: 'close', label: 'yearMonth', widget: 'yearMonth', default: 'THIS_MONTH' }
// 'PREV_MONTH' / 'NEXT_MONTH' 도 지원
yearMonthRange
년월 기간 — 시작년월/종료년월. field_from / field_to 분리 반환.
코드
{ field: 'fiscal', label: 'yearMonthRange', widget: 'yearMonthRange', default: 'THIS_YEAR' }
// getData() → { fiscal_from: '2026-01', fiscal_to: '2026-12' }
year
년도 — 4자리. 연도별 보고서 등에.
코드
{ field: 'fy', label: 'year', widget: 'year', default: 'THIS_YEAR' }
// getData() → { fy: '2026' }
week
주차 — 'YYYY-Www' 형식 (ISO 8601).
코드
{ field: 'wk', label: 'week', widget: 'week' }
// getData() → { wk: '2026-W20' }
time
시간 — 'HH:MM'. step 으로 분 단위 조정.
코드
{ field: 'mtg', label: 'time', widget: 'time', default: 'NOW', step: 600 }
// step: 600 = 10분 단위
4. 범위 · 평점 · 색 · 태그 (4종)
slider
슬라이더 — min / max / step 으로 범위 지정. 0~100 진행률 등에.
코드
{ field: 'prog', label: 'slider', widget: 'slider', min: 0, max: 100, step: 5, default: 50 }
rating
별점 — max 별 개수(기본 5). 만족도/평가에.
코드
{ field: 'score', label: 'rating', widget: 'rating', max: 5 }
// getData() → { score: 4 }
colorPicker
색상 선택 — '#RRGGBB' 반환.
코드
{ field: 'theme', label: 'colorPicker', widget: 'colorPicker', default: '#667eea' }
tagInput
태그 입력 — 엔터 또는 콤마로 추가. 콤마 구분 문자열로 반환.
코드
{ field: 'keywords', label: 'tagInput', widget: 'tagInput', placeholder: '엔터로 태그 추가' }
// getData() → { keywords: 'erp,saas,b2b' }
5. 팝업 · 파일 · 표시 (4종)
codePopup
코드 팝업 — 우측 버튼 클릭 시 모달로 검색. popup.url 지정. 모달에서 FormaModal.current().ok({code, name}) 로 결과 반환.
코드
{ field: 'cust', label: 'codePopup', widget: 'codePopup',
  popup: { url: '/pages/popup/CUS_P01.html', codeField: 'cust_cd', nameField: 'cust_nm' } }
// 팝업에서 더블클릭 → cust 필드에 코드, cust_nm 에 명칭 자동 채움
file
파일 업로드 — accept 확장자 제한, multiple 다중 선택. getData() 에서 File[] 반환.
코드
{ field: 'doc', label: 'file', widget: 'file', accept: '.pdf,.png,.jpg', multiple: true }
// FormData 만들어서 multipart 전송: const fd = new FormData(); files.forEach(f => fd.append('files', f));
display
표시 전용 (읽기/뱃지) — 입력 불가. badge: true + badgeColors 로 컬러 뱃지.
코드
{ field: 'status', label: 'display', widget: 'display',
  badge: true, badgeColors: { ACTIVE: '#10b981', INACTIVE: '#ef4444', PENDING: '#f59e0b' } }
// setData({ status: 'ACTIVE' }) — 녹색 뱃지로 표시
divider
구분선/섹션 — 폼을 시각적으로 분리. collapsible: true 로 접기/펼치기.
코드
elements: [
    { field: 'name', label: '이름' },
    { widget: 'divider', label: '추가 정보', collapsible: true },
    { field: 'memo', label: '비고', widget: 'textarea', rows: 2 }
]
공통 기능 데모 (Public API)
데이터 입출력 · 검증 · 동적 제어 · 더티 체크. 아래 버튼으로 메서드 호출 결과 즉시 확인.
// 버튼을 클릭하면 결과가 여기 표시됩니다
검색폼 패턴 (search: true)
목록 화면 상단에 가로 배치되는 형태. FormaGrid 와 함께 사용. 검색 입력 후 엔터 또는 onEnter 콜백으로 그리드 조회.
// 검색 버튼을 누르면 폼 데이터가 표시됩니다
API 레퍼런스
생성자 옵션 (7개)
옵션타입기본값설명
search Boolean false true 면 검색폼 (가로 배치)
columns Number 2 form 모드 컬럼 수
labelWidth Number 80 라벨 너비 (px)
elements Array [] 위젯 정의 배열
onChange Function null (field, value, oldValue)
onBlur Function null (field, value)
onEnter Function null (field, value)
공통 필드 속성 (9개, elements 항목)
속성타입설명
field String 데이터 필드명 (필수)
label String 라벨 텍스트
widget String 위젯 타입 (기본 'text')
required Boolean 필수 여부 (* 표시, validate 대상)
readOnly Boolean 읽기 전용
colspan Number 차지할 컬럼 수
prefix / suffix String 입력 앞/뒤 텍스트 ('₩', '원', 'kg')
helpText String 필드 아래 도움말
onChange Function (value, oldValue) 개별 필드
Public API 메서드 (18개)
메서드설명
데이터 입출력
getData() 폼 전체 데이터 반환
setData(obj) 폼 데이터 세팅 + 원본 스냅샷 저장
getField(field) / setField(field, value)개별 필드 읽기/쓰기
clear() 전체 초기화
resetToOriginal() 마지막 setData 의 원본으로 복원
검증 · 상태
validate() required 필드 검증 (false 면 에러 표시)
isDirty() 원본 대비 변경 여부
getChangedFields() 변경된 필드명 배열
동적 제어
setOptions(field, options) combo / multiCombo / select 옵션 교체
setRequired(field, boolean) 필수 여부 동적 변경
setReadonly(field, boolean) 개별 readOnly 토글
setDisabled(field, boolean) 개별 disabled 토글
setLabel(field, text) 라벨 텍스트 변경
formReadonly(boolean) 전체 읽기전용 토글
showField(field) / hideField(field) 필드 표시 / 숨김
포커스 · 라이프사이클
focus(field) 특정 필드 포커스
destroy() 위젯 정리 (document 리스너 해제)

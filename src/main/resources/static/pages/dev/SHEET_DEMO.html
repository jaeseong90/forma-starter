FormaSheet 데모

API 레퍼런스
생성자 옵션타입기본값설명
dataArraynull2D 배열 데이터
columnsArraynull컬럼 정의 [{label, width, type, readOnly}]
templateStringnull사전 정의 템플릿명 ('weekly-report')
templateDataObjectnull템플릿 바인딩 데이터
widthString'100%'시트 너비
heightNumber400시트 높이 (px)
minRowsNumber5최소 행 수
minColsNumber6최소 열 수
editableBooleantrue편집 가능 여부
showToolbarBooleantrue서식 툴바 표시
onCellChangeFunctionnull(instance, cell, col, row, value)
onSelectionChangeFunctionnull({x1, y1, x2, y2})
onReadyFunctionnull(sheet) 초기화 완료
메서드설명
getData()전체 데이터 2D 배열 반환
setData(data)2D 배열 데이터 세팅
getJsonData()템플릿 데이터 영역을 [{field:value}] 객체 배열로 반환
setJsonData(items)객체 배열로 데이터 영역 채우기
loadTemplate(name, data)템플릿 로드 + 데이터 바인딩
getCellValue(row, col)셀 값 조회
setCellValue(row, col, value)셀 값 설정
setCellStyle(row, col, style)셀 스타일 {background, fontWeight, color, textAlign}
mergeCells(row, col, colspan, rowspan)셀 병합
setReadonly(row, col, bool)읽기 전용 설정
insertRow(idx, data)행 삽입 (템플릿: 객체, 일반: 배열)
deleteRow(idx)행 삭제
findDataRow(field, value)데이터 행 검색 (템플릿 모드)
updateDataField(rowIdx, field, value)특정 필드 업데이트 (템플릿 모드)
getDataRow(rowIdx)행 데이터 객체 반환 (템플릿 모드)
getDataRowCount()데이터 행 수
exportCsv(filename)CSV 다운로드
print(title)인쇄 미리보기
undo() / redo()실행 취소 / 다시 실행
clear()전체 데이터 초기화
destroy()인스턴스 제거

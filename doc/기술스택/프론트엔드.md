# 프론트엔드 기술 스택

> **이 문서의 위상**: 기술 선택의 근거 + 디렉토리 지도. 화면 조립 관례는 `doc/프론트-패턴.md`, 위젯 API 카탈로그는 `doc/FormaForm-위젯-레퍼런스.md` 가 1차 소스.

## 핵심 기술

| 기술 | 용도 |
|---|---|
| Vanilla JavaScript (ES2020+) | 화면 로직. async/await, optional chaining 자유 사용 |
| HTML5 | 정적 마크업 + 인라인 `<script>` IIFE |
| CSS3 (`forma.css`) | CSS 변수 기반 테마 (다크모드 토글) |
| Spring Boot 정적 리소스 | `src/main/resources/static/` 디렉토리 직접 서빙 |

## 사용하지 않는 기술

| 기술 | 사유 |
|---|---|
| React / Vue / Angular | starter 의 목표는 SI 환경에서 빌드 도구 없이 즉시 배포 |
| Webpack / Vite / esbuild / Babel | 동일 사유. `<script src="">` 직접 로딩 |
| jQuery / Bootstrap / Material UI | FORMA 자체 컴포넌트(15개) 사용 — 외부 UI 라이브러리 의존 0 |
| npm / yarn / pnpm | 패키지 매니저 없음. CDN/inline 도 지양 |

> **예외**: `static/assets/js/lib/` 아래 일부 3rd-party 단일 파일(jspreadsheet, xlsx.bundle.js 등) 은 export·시트 위젯 백엔드로 사용. 모두 사전에 다운로드되어 저장소에 포함됐다.

## 화면 1개 = HTML 1파일 (인라인 `<script>` IIFE)

JS 파일 분리하지 않는다. 한 화면 = 한 파일이라 grep / 검색이 쉽고, AI 가 컨텍스트 한 번에 잡기 좋다.

```html
<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="/assets/css/forma.css">
    <!-- framework/*.js 는 main.html 의 부모 프레임에서 이미 로드됨 -->
</head>
<body>
<div id="page-ITM010">
    <div id="search"></div>
    <div id="actions"></div>
    <div id="grid1"></div>
</div>
<script>
(function() {
    const PGM = 'ITM010';
    const listener = {
        initPgm(ctx) {
            ctx.search = new FormaSearch('#search', [...]);
            ctx.grid1 = new FormaGrid('#grid1', { columns: [...] });
        },
        button: {
            search: { click: (ctx) => ctx.api.post('/itm010/selectGrid1', ctx.search.getValues())
                            .then(d => ctx.grid1.setData(d, d.totalCount)) },
            save:   { click: (ctx) => ctx.api.post('/itm010/saveGrid1', ctx.grid1.getChanges())
                            .then(() => listener.button.search.click(ctx)) },
        }
    };
    platform.startPage(PGM, listener);
})();
</script>
</body>
</html>
```

`platform.startPage(PGM, listener)` 가 권한 로딩, 툴바 자동 구성, 단축키 매핑, MDI 탭 라이프사이클을 자동 처리한다. 자세한 컨벤션은 `doc/프론트-패턴.md`.

## CSS 체계

- 모든 클래스는 `forma-` 접두사. 전역 태그 스타일 금지(다른 화면과 충돌 방지).
- 다크모드: `forma.theme.js` 가 `data-theme="dark"` 토글, CSS 변수(`--bg`, `--fg`, `--border` 등) 가 자동 전환.
- 색상·간격·폰트는 `forma.css` 상단의 CSS 변수에 집중 — 브랜딩 교체 시 변수만 갈아끼우면 된다.

## 빌드/배포

빌드 단계 없음. `./gradlew bootRun` 또는 `./gradlew bootJar` 로 만든 jar 가 `static/` 을 그대로 서빙. 변경 즉시 새로고침 (devtools 가 정적 리소스 캐시를 깸).

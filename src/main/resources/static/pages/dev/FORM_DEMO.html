FormaForm 위젯 데모

1. 텍스트 · 숫자 입력 (7종)
text · textarea · password · hidden · currency · inputMask · address
코드 보기 
new FormaForm('#g1', {
    columns: 4, labelWidth: 110,
    elements: [
        { field: 'text',     label: 'text',      placeholder: '한 줄 텍스트' },
        { field: 'number',   label: 'number',    type: 'number', suffix: '개' },
        { field: 'currency', label: 'currency',  widget: 'currency', prefix: '₩', suffix: '원' },
        { field: 'password', label: 'password',  widget: 'password' },
        { field: 'textarea', label: 'textarea',  widget: 'textarea', colspan: 4, rows: 2 },
        { field: 'mask',     label: 'inputMask', widget: 'inputMask', mask: '999-9999-9999' },
        { field: 'address',  label: 'address',   widget: 'address', colspan: 3 },
        { field: 'hidden',   widget: 'hidden' }
    ]
});
2. 선택 (8종)
combo · select · radio · checkbox · switch · multiCombo · buttonGroup · autocomplete
코드 보기 
new FormaForm('#g2', {
    columns: 4, labelWidth: 110,
    elements: [
        { field: 'combo',  label: 'combo',  widget: 'combo',  options: [{value:'1',label:'옵션1'}, ...] },
        { field: 'select', label: 'select', widget: 'select', options: [...] },
        { field: 'radio',  label: 'radio',  widget: 'radio',  options: [{value:'M',label:'남'}, ...] },
        { field: 'check',  label: 'checkbox', widget: 'checkbox', checkLabel: '동의' },
        { field: 'switch', label: 'switch', widget: 'switch', onLabel: 'ON', offLabel: 'OFF' },
        { field: 'multi',  label: 'multiCombo', widget: 'multiCombo', colspan: 2, options: [...] },
        { field: 'btnGrp', label: 'buttonGroup', widget: 'buttonGroup', options: [...] },
        { field: 'auto',   label: 'autocomplete', widget: 'autocomplete', colspan: 2, options: [...] }
    ]
});

코드 보기 
new FormaForm('#g3', {
    columns: 4, labelWidth: 130,
    elements: [
        { field: 'date',    label: 'date',           widget: 'date', default: 'TODAY' },

        { field: 'week',    label: 'week',           widget: 'week' },
        { field: 'time',    label: 'time',           widget: 'time', default: 'NOW' }

4. 범위 · 평점 · 색 · 태그 (4종)
slider · rating · colorPicker · tagInput
코드 보기 
new FormaForm('#g4', {
    columns: 4, labelWidth: 110,
    elements: [
        { field: 'slider', label: 'slider',      widget: 'slider', min: 0, max: 100, step: 5, default: 50 },
        { field: 'rating', label: 'rating',      widget: 'rating', max: 5 },
        { field: 'color',  label: 'colorPicker', widget: 'colorPicker', default: '#667eea' },

5. 팝업 · 파일 · 표시 (4종)
codePopup · file · display · divider
코드 보기 
new FormaForm('#g5', {
    columns: 4, labelWidth: 110,
    elements: [
        { widget: 'divider', label: '거래처 정보', collapsible: true },
        { field: 'popup', label: 'codePopup', widget: 'codePopup', colspan: 2,
          popup: { url: '/pages/popup/CUS_P01.html', codeField: 'cust_cd', nameField: 'cust_nm' } },
        { field: 'file',  label: 'file',      widget: 'file', colspan: 2, accept: '.pdf,.png,.jpg', multiple: true },
        { field: 'badge', label: 'display',   widget: 'display', default: 'ACTIVE',
          badge: true, badgeColors: { ACTIVE: '#10b981', INACTIVE: '#ef4444' } }
    ]
});
공통 기능 데모
데이터 입출력 · 검증 · 동적 제어 · 더티 체크. 아래 버튼으로 메서드 호출 결과 즉시 확인.
// 버튼을 클릭하면 결과가 여기 표시됩니다
검색폼 패턴
search: true 옵션 — 목록 화면 상단에 가로 배치되는 형태. FormaGrid 와 함께 사용.
// 검색 버튼을 누르면 폼 데이터가 표시됩니다
API 레퍼런스
생성자 옵션 · 공통 필드 속성 · 위젯 카탈로그 · Public API 메서드.
생성자 옵션 (7개)
옵션타입기본값설명
search Boolean false true 면 검색폼 (가로 배치)
columns Number 2 form 모드 컬럼 수
labelWidth Number 80 라벨 너비 (px)
elements Array [] 위젯 정의 배열
onChange Function null (field, value, oldValue)
onBlur Function null (field, value)
onEnter Function null (field, value)
공통 필드 속성 (9개, elements 항목)
속성타입설명
field String 데이터 필드명 (필수)
label String 라벨 텍스트
widget String 위젯 타입 (기본 'text')
required Boolean 필수 여부 (* 표시, validate 대상)
readOnly Boolean 읽기 전용
colspan Number 차지할 컬럼 수
prefix / suffix String 입력 앞/뒤 텍스트 ('₩', '원', 'kg')
helpText String 필드 아래 도움말
onChange Function (value, oldValue) 개별 필드
위젯 카탈로그 (30개)
widget설명getValue() 반환주요 속성
텍스트 · 숫자 (7)
text 텍스트 입력 (기본) String / Number placeholder, maxLength, type, min, max, step
textarea 여러 줄 텍스트 String rows, placeholder
password 비밀번호 (눈 토글) String placeholder
hidden 숨김 필드 String —
currency 금액 (콤마 포맷) Number prefix, suffix
inputMask 입력 마스크 String mask
address 카카오 주소검색 field_zip / _addr / _detail —
선택 (8)
combo 검색 드롭다운 (+popup) String options, code, popup, dependsOn
select 단순 드롭다운 String options, code
radio 라디오 String options
checkbox 체크박스 'Y' / 'N' checkLabel
switch ON/OFF 토글 'Y' / 'N' onLabel, offLabel
multiCombo 복수 선택 'A,B,C' options
buttonGroup 버튼 그룹 선택 String options
autocomplete 자동완성 String options, fetchUrl
날짜 · 기간 (7)
date 날짜 (캘린더) 'YYYY-MM-DD' default: 'TODAY'
dateRange 기간 (프리셋) field_from / _todefault, presets
yearMonth 년월 'YYYY-MM' default
yearMonthRange 년월 기간 field_from / _todefault: 'THIS_YEAR'
year 년도 String default: 'THIS_YEAR'
week 주차 'YYYY-Www' —
time 시간 'HH:MM' default: 'NOW', step
범위 · 평점 · 색 · 태그 (4)
slider 슬라이더 (범위) Number min, max, step
rating 별점 Number max (기본 5)
colorPicker 색상 선택 '#RRGGBB' default
tagInput 태그 입력 'tag1,tag2' placeholder
팝업 · 파일 · 표시 (4)
codePopup 코드 검색 팝업 String popup: {url, codeField, nameField}
file 파일 업로드 File[] accept, multiple, buttonLabel
display 읽기전용 / 뱃지 String badge, badgeColors, options
divider 구분선 / 섹션 — label, collapsible
Public API 메서드 (18개)
메서드설명
데이터 입출력
getData() 폼 전체 데이터 반환
setData(obj) 폼 데이터 세팅 + 원본 스냅샷 저장
getField(field) / setField(field, value)개별 필드 읽기/쓰기
clear() 전체 초기화
resetToOriginal() 마지막 setData 의 원본으로 복원
검증 · 상태
validate() required 필드 검증 (false 면 에러 표시)
isDirty() 원본 대비 변경 여부
getChangedFields() 변경된 필드명 배열
동적 제어
setOptions(field, options) combo / multiCombo / select 옵션 교체
setRequired(field, boolean) 필수 여부 동적 변경
setReadonly(field, boolean) 개별 readOnly 토글
setDisabled(field, boolean) 개별 disabled 토글
setLabel(field, text) 라벨 텍스트 변경
formReadonly(boolean) 전체 읽기전용 토글
showField(field) / hideField(field) 필드 표시 / 숨김
포커스 · 라이프사이클
focus(field) 특정 필드 포커스
destroy() 위젯 정리 (document 리스너 해제)
